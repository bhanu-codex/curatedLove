💝 curatedLove
The AI-Powered Boutique Concierge

curatedLove is a high-end personal gifting assistant designed to bridge the gap between generic suggestions and thoughtful, bespoke gifting experiences.
By analyzing the recipient's age, gender, and emotional depth of your relationship, it generates three distinct gifting strategies for any occasion.

✨ Why curatedLove?

Direct AI chats can feel overwhelming. curatedLove filters the noise and delivers curated inspiration through three carefully designed approaches:

🎁 The Safe Bet – Timeless, reliable gifts that never miss.

🚀 The Wildcard – Bold, creative, and unexpected surprises.

🌟 The Experience – Memory-making moments over material things.

🚀 Unique Features

🧠 Emotional Intelligence
Adjusts card message tone based on relationship depth
(Professional 🤝 → Super Close 🤞)

🎯 Age & Gender Apt Suggestions
Ensures gifts are socially and practically appropriate

🔒 Local & Private
Runs entirely on your machine — no data leaves your system

⚡ One-Click Utility
Copy-ready card messages with a single button

📦 Installation
git clone https://github.com/your-username/curatedLove.git
cd curatedLove
pip install -r requirements.txt

Make sure Ollama is installed and pull the model:

ollama pull phi3:mini
▶️ Run the App
streamlit run app.py

Open in browser:

http://localhost:8501
